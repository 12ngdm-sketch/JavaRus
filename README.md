# JavaRus

Русский язык программирования. Java с командами на русском.

## О проекте

JavaRus — это язык программирования, основанный на Java, но с командами на русском языке. Цель — сделать программирование доступным для всех, кто говорит на русском.

## Версия

**0.1** — первый рабочий релиз.

## Пример кода

```java
вывести("Привет, мир!");
целое x = 5;
если (x > 3) { вывести("Больше трёх"); }
```

Возможности

· Переменные (целое, строка, дробное, логическое)
· Условия (если)
· Циклы (пока)
· Создание объектов (игрок, камера, комната, стена, враг)
· Кнопки с действиями
· Действия (двигать, выстрелить, установить hp)
