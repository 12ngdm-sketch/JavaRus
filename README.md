# JavaRus

О проекте

JavaRus — это язык программирования, основанный на Java, но с командами на русском языке. Цель — сделать программирование доступным для всех, кто говорит на русском.

версия 0.0 пока просто файлы и папки 

Структура проекта
проект javarus/
├── компилятор/         
├── здесь писать код/    
├── сюда картинки.../    спрайты до 248 пикселей 
├── здесь апк/           
└── Инструкция.txt       
 Как пользоваться

1. Скачай архив.
2. Открой `Инструкция.txt`.
3. Начни писать код на JavaRus.

 Пример кода

```java
вывести("Привет, мир!");
целое x = 5;
если (x > 3) {
    вывести("Больше трёх");
}
Планы

 Рабочий компилятор (ver 0.1)
 Перевод на другие языки
