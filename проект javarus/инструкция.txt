================================
   JavaRus — ИНСТРУКЦИЯ
================================

Привет, дорогой пользователь! Это программа JavaRus от Nektor.
Я помогу понять, как создавать игры и приложения.

=== ШАГ 1: УСТАНОВКА ПРИЛОЖЕНИЙ ===
Первым делом установи приложения:
- Termux
- Jvdroid
- Pydroid

(Android SDK устанавливается отдельно через Termux — см. ниже).

=== ШАГ 2: НАСТРОЙКА TERMUX ===
Зайди в Termux и введи эти команды (можно сразу все):

pkg update && pkg upgrade -y
pkg install openjdk-17 -y
pkg install clang -y
pkg install python -y
pkg install wget -y
pkg install aapt2 apksigner gradle -y

=== ШАГ 3: УСТАНОВКА ANDROID SDK ===
После этих команд установи Android SDK:

wget https://raw.githubusercontent.com/Willie169/termux-android-sdk-ndk/refs/heads/main/install.sh && chmod +x install.sh && ./install.sh

(Внимание: скачивается ~350 МБ. Это нормально.)

=== ШАГ 4: ПЕРЕХОД В ПАПКУ ПРОЕКТА ===
cd /sdcard/проект\ javarus/
Твой путь может отличаться.

=== ШАГ 5: КАК ПОЛЬЗОВАТЬСЯ ===
1. Открой папку "здесь писать код"
2. Зайди в "игры" или "приложения"
3. Создай свою папку (например, "МояИгра")
4. Наблюдатель автоматически создаст:
   - файл "МояИгра.jrus" (для кода)
   - скрипт "МояИгра.sh" (для запуска)
   - папку для спрайтов

5. Напиши код на JavaRus в файл "МояИгра.jrus"
6. Положи PNG-картинки в папку "сюда картинки разрешение до 248/МояИгра"
7. Запусти "МояИгра.sh" через Termux:
   cd "здесь писать код/компилировать/игры"
   bash МояИгра.sh

8. APK появится в папке "здесь апк"

=== ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ ===
- Проверь, что все папки на месте
- Проверь, что код написан правильно
- Проверь, что спрайты в нужной папке
- Если Termux сбросился — просто установи пакеты заново (шаг 2)
